L234: # CPU deploymentcite0†link
L235: 
L236: IREE supports efficient program execution on CPU devices by using cite137†LLVM†llvm.org to compile all dense computations in each program into highly optimized CPU native instruction streams, which are embedded in one of IREE's deployable formats.
L237: 
L238: To compile a program for CPU execution:
L239: 
L240:   1. Pick a CPU target supported by LLVM. By default, IREE includes these LLVM targets:
L241: 
L242:      * X86
L243:      * ARM
L244:      * AArch64
L245:      * RISCV
L246: Other targets may work, but in-tree test coverage and performance work is focused on that list.
L247: 
L248:   2. Pick one of IREE's supported executable formats:
L249: 
L250: Executable Format  | Description
L251: --- | ---
L252: Embedded ELF  | (Default) Portable, high performance dynamic library
L253: System library  | Platform-specific dynamic library (.so, .dll, etc.)
L254: VMVX  | Reference target
L255: 
L256: At runtime, CPU executables can be loaded using one of IREE's CPU HAL devices:
L257:   * `local-task`: asynchronous, multithreaded device built on IREE's "task" system
L258:   * `local-sync`: synchronous, single-threaded devices that executes work inline

L359: ## Compile and run a programcite28†link
L360: 
L361: With the requirements out of the way, we can now compile a model and run it.
L362: ### Compile a programcite29†link
L363: 
L364: The IREE compiler transforms a model into its final deployable format in several sequential steps. A model authored with Python in an ML framework should use the corresponding framework's import tool to convert into a format (i.e., cite144†MLIR†mlir.llvm.org ) expected by the IREE compiler first.
L365: Using a cite145†MobileNet model†github.com as an example, import using IREE's cite14†ONNX importer :
L366: 
L367:     `# Download the model you want to compile and run.
L368:     wget https://github.com/onnx/models/raw/refs/heads/main/validated/vision/classification/mobilenet/model/mobilenetv2-10.onnx
L369: 
L370:     # Import to MLIR using IREE's ONNX importer.
L371:     pip install iree-base-compiler[onnx]
L372:     iree-import-onnx mobilenetv2-10.onnx --opset-version 17 -o mobilenetv2.mlir
L373:     `
L374: Then run the following command to compile with the `local` device, `llvm-cpu` target compilation backend, and recommended optimization flags:
L375: 
L376:     `iree-compile \
L377:         --iree-hal-target-device=local \
L378:         --iree-hal-local-target-device-backends=llvm-cpu \
L379:         --iree-llvmcpu-target-cpu=host \
L380:         --iree-opt-level=O2 \
L381:         --iree-opt-data-tiling \
L382:         mobilenetv2.mlir -o mobilenet_cpu.vmfb
L383:     `
L384: 
L385: Tip - Target CPUs and CPU features
L386: By default, the compiler will use a generic CPU target which will result in poor performance. A target CPU or target CPU feature set should be selected using one of these options:
L387: 
L388:   * `--iree-llvmcpu-target-cpu=...`
L389:   * `--iree-llvmcpu-target-cpu-features=...`
L390: 
L391: When not cross compiling, passing `--iree-llvmcpu-target-cpu=host` is usually sufficient on most devices.
L392: 
L393: Tip - Compiler Optimizations
L394: Use `--iree-opt-level=[O0,O1,O2,O3]` to enable additional compiler optimizations. The default value of `O0` enables only minimal optimizations while higher levels enable progressively more aggressive optimizations. See cite39†Optimization Options for more details.
L395: 
L396: Tip - Data-Tiling
L397: Use `--iree-opt-data-tiling` to enable the optimization that IREE developers have been working on. The option is default off for many reasons, but it has been used for performance when users target CPU. See cite146†Data-Tiling for more details.
L398: #### Choosing CPU targetscite30†link
L399: The `--iree-llvmcpu-target-triple` flag tells the compiler to generate code for a specific type of CPU. You can see the list of supported targets with `iree-compile --iree-llvmcpu-list-targets`, or use the default value of "host" to let LLVM infer the triple from your host machine (e.g. `x86_64-linux-gnu`).
L400: 
L401:     `$ iree-compile --iree-llvmcpu-list-targets
L402: 
L403:       Registered Targets:
L404:         aarch64    - AArch64 (little endian)
L405:         aarch64_32 - AArch64 (little endian ILP32)
L406:         aarch64_be - AArch64 (big endian)
L407:         arm        - ARM
L408:         arm64      - ARM64 (little endian)
L409:         arm64_32   - ARM64 (little endian ILP32)
L410:         armeb      - ARM (big endian)
L411:         riscv32    - 32-bit RISC-V
L412:         riscv64    - 64-bit RISC-V
L413:         wasm32     - WebAssembly 32-bit
L414:         wasm64     - WebAssembly 64-bit
L415:         x86        - 32-bit X86: Pentium-Pro and above
L416:         x86-64     - 64-bit X86: EM64T and AMD64
L417:     `
L418: ### Run a compiled programcite31†link
L419: 
L420: To run the compiled program:
L421:
