L17@P0: INTRODUCTION
L18@P0: Formal language learning (Gold, 1969) has been a topic of concern for cognitive science
L19@P0: and artificial intelligence. It is the task of inducing a computational description of a formal
L20@P0: language from a sequence of positive and negative examples of strings in the target language. Neural information processing approaches to this problem involve the use of recurrent networks that embody the internal state mechanisms underlying automata models
L21@P0: (Cleeremans et aI., 1989; Elman, 1990; Pollack, 1991; Giles et aI, 1992; Watrous & Kuhn,
L22@P0: 1992). Unlike traditional automata-based approaches, learning systems relying on recurrent
L23@P0: networks have an additional burden: we are still unsure as to what these networks are
L24@P0: doing.Some researchers have assumed that the networks are learning to simulate finite state

L26@P1: machines (FSMs) in their state dynamics and have begun to extract FSMs from the networks' state transition dynamics (Cleeremans et al., 1989; Giles et al., 1992; Watrous &
L27@P1: Kuhn, 1992). These extraction methods employ various clustering techniques to partition
L28@P1: the internal state space of the recurrent network into a finite number of regions corresponding to the states of a finite state automaton.
L29@P1: This assumption of finite state behavior is dangerous on two accounts. First, these extraction techniques are based on a discretization of the state space which ignores the basic definition of information processing state. Second, discretization can give rise to incomplete
L30@P1: computational explanations of systems operating over a continuous state space.

L33@P1: extraction system. The basis of this claim rests upon the definition of information processing
L34@P1: state. Information processing (lP) state is the foundation underlying automata theory. Two
L35@P1: IP states are the same if and only if they generate the same output responses for all possible
L36@P1: future inputs (Hopcroft & Ullman, 1979). This definition is the fulcrum for many proofs and

L177@P5: CONCLUSION
L178@P5: Using recurrent neural networks as the representation underlying the language learning task
L179@P5: has revealed some inherent problems with the concept of this task. While formal languages
L180@P5: have mathematical validity, looking for language induction in physical systems is questionable, especially if that system operates with continuous internal states. As I have shown,
L181@P5: there are two major problems with the extraction of a learned automata from our models.
L182@P5: First, sensitivity to initial conditions produces nondeterministic machines whose trajectories are specified by both the initial state of the network and the dynamics of the state transformation. The dynamics provide the shape of the eventual attractor. The initial conditions
L183@P5: specify the allowable trajectories toward that attractor. While clustering methods work in
L184@P5: the analysis of feed-forward networks because of neighborhood preservation (as each layer
L185@P5: is a homeomorphism), they may fail when applied to recurrent network state space transformations. FSM construction methods which look for single transitions between regions
L186@P5: will not help in this case because the network eventually separates initially nearby states
L187@P5: across several FSM state regions.
L188@P5: The second problem with the extraction of a learned automata from recurrent network is
L189@P5: that trivial changes in observation strategies can cause one to induce behavioral descriptions from a wide range of computational complexity classes for a single system. It is the
L190@P5: researcher's bias which determines that a dynamical system is equivalent to a finite state
L191@P5: automata. Fool's Gold: Extracting Finite State Machines from Recurrent Network Dynamics 507
L192@P6: One response to the first problem described above has been to remove and eliminate the
L193@P6: sources of nondeterminism from the mechanisms. Zeng et. a1 (1993) corrected the secondorder recurrent network model by replacing the continuous internal state transformation with
L194@P6: a discrete step function. (The continuous activation remained for training purposes.) This
L195@P6: move was justified by their focus on regular language learning, as these languages can be recognized by finite state machines. This work is questionable on two points, however. First,
L196@P6: tractable algorithms already exist for solving this problem (e.g. Angluin, 1987). Second, they
L197@P6: claim that the network is self-clustering the internal states. Self-clustering occurs only at the
L198@P6: comers of the state space hypercube because of the discrete activation function, in the same
L199@P6: manner as a digital sequential circuit "clusters" its states. Das and Mozer (1994), on the other
L200@P6: hand, have relocated the clustering algorithm. Their work focused on recurrent networks that
L201@P6: perform internal clustering during training. These networks operate much like competitive
L202@P6: learning in feed-forward networks (e.g. Rumelhart and Zipser, 1986) as the dynamics of the
L203@P6: learning rules constrain the state representations such that stable clusters emerge.
L204@P6: The shortcomings of finite state machine extraction must be understood with respect to the
L205@P6: task at hand. The actual dynamics of the network may be inconsequential to the final product if one is using the recurrent network as a pathway for designing a finite state machine.
L206@P6: In this engineering situation, the network is thrown away once the FSM is extracted. Neural
L207@P6: network training can be viewed as an "interior" method to finding discrete solutions. It is
L208@P6: interior in the same sense as linear programming algorithms can be classified as either edge
L209@P6: or interior methods. The former follows the edges of the simplex, much like traditional
L210@P6: FSM learning algorithms search the space of FSMs. Internal methods, on the other hand,
L211@P6: explore search spaces which can embed the target spaces. Linear programming algorithms
L212@P6: employing internal methods move through the interior of the defined simplex. Likewise,
L213@P6: recurrent neural network learning methods swim through mechanisms with mUltiple finite
L214@P6: state interpretations. Some researchers, specifically those discussed above, have begun to
L215@P6: bias recurrent network learning to walk the edges (Zeng et al, 1993) or to internally cluster
L216@P6: states (Das & Mozer, 1994).
L217@P6: In order to understand the behavior of recurrent networks, these devices should be regarded
L218@P6: as dynamical systems (Kolen, 1994). In particular, most common recurrent networks are
L219@P6: actually iterated mappings, nonlinear versions of Barnsley's iterated function systems
L220@P6: (Barnsley, 1988). While automata also fall into this class, they are a specialization of
L221@P6: dynamical systems, namely discrete time and state systems. Unfortunately, information
L222@P6: processing abstractions are only applicable within this domain and do not make any sense
L223@P6: in the broader domains of continuous time or continuous space dynamical systems.
