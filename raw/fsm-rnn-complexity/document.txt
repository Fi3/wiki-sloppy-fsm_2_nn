L19@P0: 1 Introduction
L20@P0: The topic of this paper is understanding how efficiently neural networks scale to
L21@P0: large problems. Although there are many ways to measure efficiency, we shall be
L22@P0: concerned with node complexity, which as its name implies, is a calculation of the
L23@P0: required number of nodes. Node complexity is a useful measure of efficiency since
L24@P0: the amount of resources required to implement or even simulate a recurrent neural
L25@P0: network is typically related to the number of nodes. Node complexity can also
L26@P0: be related to the efficiency of learning algorithms for these networks and perhaps
L27@P0: to their generalization ability as well. We shall focus on the node complexity of
L28@P0: recurrent neural network implementations of finite state machines (FSMs) when
L29@P0: the nodes of the network are restricted to threshold logic units.

L31@P1: In the 1960s it was shown that recurrent neural networks are capable of implementing arbitrary FSMs. The first result in this area was due to Minsky [7], who
L32@P1: showed that m-state FSMs can be implemented in a fully connected recurrent neural network. Although circuit complexity was not the focus of his investigation it
L33@P1: turns out that his construction, yields 0 (m) nodes. This construction was also
L34@P1: guaranteed to use weight values limited to the set {I, 2}. Since a recurrent neural
L35@P1: network with k hard-limiting nodes is capable of representing as many as 2k states,
L36@P1: one might wonder if an m-state FSM could be implemented by a network with
L37@P1: log m nodes. However, it was shown in [1] that the node complexity for a standard
L38@P1: fully connected network is n ((m log m)1/3). They were also able to improve upon
L39@P1: Minsky's result by providing a construction which is guaranteed to yield no more
L40@P1: than 0 (m3/ 4 ) nodes. In the same paper lower bounds on node complexity were investigated as the network was subject to restrictions on the possible range of weight
L41@P1: values and the fan-in and fan-out of the nodes in the network. Their investigation
L42@P1: was limited to fully connected recurrent neural networks and they discovered that
L43@P1: the node complexity for the case where the weights are restricted to a finite size set
L44@P1: is n (y'm log m) . Alternatively, if the nodes in the network were restricted to have a
L45@P1: constant fan-in then the node complexity becomes n (m) . However, they left open
L46@P1: the question of how tight these bounds are and if they apply to variations on the
L47@P1: basic architecture. Other recent work includes investigation of the node complexity
L48@P1: for networks with continuous valued nonlinearities [14]. However, it can also be
L49@P1: shown that when continuous nonlinearities are used, recurrent neural networks are
L50@P1: far more powerful than FSMs; in fact, they are Turing equivalent [13].
L51@P1: In this paper we improve the upper bound on the node complexity for the unrestricted case to 0 (yIm). We also provide upper bounds that match the lower
L52@P1: bounds above for various restrictions. Specifically, we show that a node complexity
L53@P1: of 0 ( y'm log m) can be achieved if the weights are restricted to the set {-I, I} , and
L54@P1: that the node complexity is 0 (m) for the case when the fan-in of each node in the
L55@P1: network is restricted to two. Finally, we explore the possibility that implementing
L56@P1: finite state machines in more complex models might yield a lower node complexity.
L57@P1: Specifically, we explore the node complexity of a general recurrent neural network
L58@P1: topology, that is capable of simulating a variety of popular recurrent neural network architectures. Except for the unrestricted case, we will show that the node
L59@P1: complexity is no different for this architecture than for the fully connected case if
L60@P1: the number of feedback variables is limited to rlog m 1, i.e. if the state of the FSM
L61@P1: is encoded optimally in a subset of the nodes. We leave it as an open question if a
L62@P1: sparser encoding can lead to a more efficient implementation.

L248@P6: 6 Summary
L249@P6: Q.E.D.
L250@P6: In summary, we provide new bounds on the node complexity of implementing FSMs
L251@P6: with recurrent neural networks. These upper bounds match lower bounds developed in [1] for fully connected recurrent networks when the size of the weight set
L252@P6: or the fan-in of each node is finite. Although one might speculate that more complex networks might yield more efficient constructions, we showed that these lower
L253@P6: bounds do not change for restrictions on weights or fan-in, at least when the state
L254@P6: of the FSM is encoded optimally in a subset of flog m 1 nodes. When the network
L255@P6: is unrestricted, this lower bound matches our upper bound. We leave it as an open
L256@P6: question if a sparser encoding of the state variables can lead to a more efficient
L257@P6: implementation.
L258@P6: One interesting aspect of this study is that there is really not much difference
L259@P6: in efficiency when the network is totally unrestricted and when there are severe
L260@P6: restrictions placed on the weights. Assuming that our bounds are tight, then there 366 Home and Hush
L261@P7: is only a y'log m penalty for restricting the weights to either -1 or 1. To get some
L262@P7: idea for how marginal this difference is consider that for a finite state machine with
L263@P7: m = 18 x 1018 states, y'log m is only eight!
