L310@P2: 4 THRESHOLD LOGIC EXTRACTION
L311@P2: 4.1 Problem Formulation
L312@P2: Given a TLN with multiple TLGs having the same disjoint decomposition option, it is possible to extract a common decomposition TLF
L313@P2: for logic sharing among the TLGs. Such an extraction operation may
L314@P2: reduce interconnect complexity of the TLN. To compute extraction
L315@P2: candidates, we define extraction set and extraction pair of a TLF as
L316@P2: follows.
L317@P2: Definition 3. An extraction set is a set of nodes in a GDL whose
L318@P2: corresponding variable set forms a legal bound set for disjoint-support
L319@P2: decomposition. A set with contiguous type-0 (resp. type-1) nodes is
L320@P2: called a type-0 extraction set (resp. type-1 extraction set). An extraction pair (S,v) consists of an extraction set S and a corresponding TLG
L321@P2: v where S comes from.
L322@P2: Example 4. For the TLN in Figure 3(a), the set S = {(x3, ∅, {0}),
L323@P2: (x4, ∅, {0})} is a type-0 extraction set, and (S,v1) is an extraction pair.
L324@P2: Problem 1 (Threshold Logic Extraction). Given a TLN, the
L325@P2: threshold logic extraction problem seeks to find common decomposition TLFs for logic sharing among the TLGs such that the total number
L326@P2: of interconnections in the TLN is minimized while the function of the
L327@P2: revised TLN remains unchanged.
