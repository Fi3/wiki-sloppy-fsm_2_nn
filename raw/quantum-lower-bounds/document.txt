L308@P3: Our goal is to compute some Boolean function f of X =
L309@P3: (x0, . . . , xN−1), where X is given as a black-box: calling
L310@P3: the black-box on i returns the value of xi. We want to use
L311@P3: as few queries as possible.
L312@P3: A classical algorithm that computes f by using (adaptive) black-box queries to X is called a decision tree, since it
L313@P3: can be pictured as a binary tree where each node is a query,
L314@P3: each node has the two outcomes of the query as children,
L315@P3: and the leaves give answer f(X) = 0 or f(X) = 1. The
L316@P3: cost of such an algorithm is the number of queries made on
L317@P3: the worst-case X, so the cost is the depth of the tree. The
L318@P3: decision tree complexity D(f) of f is the cost of the best decision tree that computes f. Similarly we can define R(f)
L319@P3: as the expected number of queries on the worst-case X for
L320@P3: randomized algorithms that compute f with bounded-error.

L322@P3: queries and other operations can now be made in quantum
