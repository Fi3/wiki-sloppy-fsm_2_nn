# Finite state machines to neural networks

## Focus

This wiki studies converting finite state machines into neural networks. The user established this focus on 2026-10-07. The starting machine model and target neural architecture are still to be chosen.

The user has supplied a [reading list](../raw/reading-list-original-order.md). Its [queue](questions/reading-queue.md) tracks first-pass summaries, confirmed duplicates, access problems and remaining review work.

## Research goals

- How should states, input symbols, and outputs be represented?
- How can a transition function be implemented by network operations?
- Which constructions reproduce a machine exactly, and which learn an approximation?
- What assumptions about activations, precision, and execution are needed?
- How should behavior be checked over input sequences, including edge cases?
- How do network size and construction complexity relate to machine size?

These are research questions, not established claims. Narrow them as sources arrive.

## What to capture from each construction

Record the machine definition, encoding, architecture, parameter construction or training procedure, execution semantics, correctness evidence, and limitations. Keep mathematical constructions, empirical results, and proposed experiments distinct.
